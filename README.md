# Project Name: Victory Lane - Address Management System

## Project Description
Victory Lane is a responsive web application designed as a Pit Crew Address Manager. It provides a seamless, NASCAR-themed experience for managing contact information, transitioning from a static JavaScript environment to a dynamic, database-driven platform. Key features include real-time address registration, a searchable database, and full administrative control over records.

## Project Tasks
- **Task 1: Set up the development environment**
  - Created the project folder structure and generic HTML/CSS shell files.
  - Configured the Git and GitHub repository for version control.
- **Task 2: Design the application**
  - Defined the database design, including columns and data types for the addresses table.
  - Planned the "Victory Lane" user interface and user experience.
- **Task 3: Develop the frontend**
  - Implemented a responsive UI using HTML and CSS.
  - Separated display logic into dedicated View files to follow MVC architectural standards.
- **Task 4: Develop the backend**
  - Set up server-side processing using PHP.
  - Created Controllers to handle user input and direct data flow between components.
- **Task 5: Implement authentication**
  - Established the **ecpi_user** account with specific database permissions.
  - Configured secure credentials for database connectivity.
- **Task 6: Connect to a database**
  - Implemented the database connection logic to link the front-end to MySQL.
  - Developed the **sdc310_midterm** database to store pit crew data and address records.
- **Task 7: Test the application**
  - Performed comprehensive functional testing on all CRUD operations to identify bugs.
  - Debugged synchronization issues between the search filter and database deletions.
- **Task 8: Deploy the application**
  - Managed the transition from static GitHub Pages to a dynamic environment.
  - Ensured the application infrastructure supported PHP and SQL operations.
- **Task 9: Document the project**
  - Created a comprehensive work breakdown and weekly status reports.
  - Wrote developer documentation covering lessons learned and architectural shifts.
